# Summary 

This is the static website content for the Arnprior Board Gamers website. Repo hosted with Netifly and using stitches from [codestitch](https://codestitch.app/)


# Dev Environment


## Vite

    npm create vite@latest arnprior-board-gamers
    cd arnprior-board-gamers
    npm install

Once the site was configured correctly enough

    npm run dev

## Git

    git init
    git add .
    git commit -m "Initial commit"

    git remote add origin https://github.com/usernameE/arnprior-board-gamers.git
    git branch -M main
    git push -u origin main
